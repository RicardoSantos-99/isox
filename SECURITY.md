# Política de segurança

Este pacote inclui um módulo de assinatura digital
(`Isox.Xmldsig`) usado por sistemas que processam mensagens
financeiras. Reporte qualquer suspeita de vulnerabilidade em particular,
nunca por issue pública — canonicalização, verificação de assinatura ou
qualquer forma de bypass de validação são consideradas críticas.

Para reportar, use a aba "Security" do repositório no GitHub (Security
Advisories) ou abra contato direto com o mantenedor. Inclua passos para
reproduzir e o impacto esperado; uma resposta inicial pode levar alguns
dias.

`Isox.Xmldsig.TestCA` gera certificados descartáveis e **nunca**
deve ser usado fora de testes — não é uma vulnerabilidade reportável, é a
função documentada do módulo.
